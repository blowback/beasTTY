- (outcome) Designed 'terminal->local pull': select filenames in the terminal, drag onto a small in-app pane that is a view over SLIDE-recv's persisted FileSystemDirectoryHandle; the drop auto-types 'SLIDE S <files>' (via existing tx-sink pushTxBytes) so the device sends them, and they land in the pane's folder. No DownloadURL/service-worker/firmware needed — recv + paste-pump/tx-sink + selection.js already existed. Cost ~3 days; the filename parse from selected text is the only hard code. Guardrail: preview the composed 'SLIDE S ...' line before it commits so a bad parse is reviewable, not silent.
